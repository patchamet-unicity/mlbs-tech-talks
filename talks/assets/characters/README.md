# characters — ตัวละครประจำ talks

Pixel sprite สองตัว (คน + หุ่นยนต์ AI) เป็น **shared asset** ใช้ได้ทุก talk
เริ่มทำครั้งแรกสำหรับ talk `2026-09-ai-usage-levels` (สถานะ: draft)

| ไฟล์ | คืออะไร |
| --- | --- |
| `build-sprites.py` | **ต้นทาง** — แก้ทรง/สี/เฟรมที่นี่ที่เดียว แล้วรัน `python build-sprites.py` |
| `characters.js` | ผลลัพธ์ generate — สไลด์เรียกใช้ตัวนี้ **ห้ามแก้มือ** |
| `preview.html` | หน้าเปิดดูตัวละครในเบราว์เซอร์ (generate เหมือนกัน) |

## เรียกใช้ในสไลด์

```html
<script src="../../assets/characters/characters.js"></script>
<div data-char="human"></div>
<div data-char="robot"></div>
```

ปรับขนาดด้วย CSS var `--char-size` (ค่าเริ่มต้น 180px)
อนิเมชันหายใจ/ลอยแปะให้อัตโนมัติ และเคารพ `prefers-reduced-motion`

## Pipeline

วาดกริดครึ่งซ้าย 20 คอลัมน์ → mirror เป็น 40 → เติมเส้นขอบอัตโนมัติ
(ช่องโปร่งที่ติดตัวละครกลายเป็นสีขอบ) ความละเอียด 40×51
ใช้แค่ Python 3 stdlib ไม่ต้อง pip อะไร

ข้อจำกัดปัจจุบัน: mirror ทำให้ทุกท่า**สมมาตรซ้ายขวา** — ท่าข้างเดียว
(ยกมือข้างเดียว, หันหัว 3/4) ต้องเพิ่ม asymmetric layer ก่อน (ดูแผนล่าง)

## แผนต่อไป (ยังไม่ทำ)

- asymmetric layer: วาดทับเต็มความกว้าง 40 คอลัมน์หลัง mirror ก่อนทำ outline
- เฟรมเพิ่ม: ตาเหลือบซ้าย/ขวา, ปากเปิด (พูด), แขนยก, เอียงตัว
- emotion sets (สลับเฉพาะโซนตา) — คน: ปกติ/ยิ้ม/คิดหนัก/ทึ่ง,
  หุ่น: ปกติ/ดีใจ/กำลังคิด/เออเรอร์
- การขยับ: เอียงตัว/ลอยซ้ายขวา/speech bubble ทำด้วย CSS-JS ครอบข้างนอก
  (อาจใช้ anime.js ช่วย choreography) — ตัวสไปรต์รับผิดชอบแค่เฟรม
