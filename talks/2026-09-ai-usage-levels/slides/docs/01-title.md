## กลไกสำคัญ: คลาส `bN` / `bN-in`

นี่คือหัวใจของไฟล์นี้ **ต้องเข้าใจก่อนแก้อะไร**

| คลาสบน `.stage` | หมายถึง | เป็น CSS แบบไหน |
| --- | --- | --- |
| `bN` | ท่า**จบ**ของ beat นั้น (settled) | `transform` / `opacity` ธรรมดา |
| `bN-in` | กำลังเล่นอนิเมชัน**เข้า** beat นั้น | `animation` |

ทั้งสองคลาสถูกใส่พร้อมกันตอนเริ่ม beat — CSS animation มี priority สูงกว่า
normal declaration อยู่แล้ว ระหว่างเล่นจึงเห็น animation ส่วนพอ **ถอด `bN-in` ออก**
ปุ๊บ ก็ตกกลับไปใช้ท่าจบทันที = **snap**

กลไกนี้เลยรองรับทั้งสามอย่างด้วยโค้ดชุดเดียว:

- **snap** (คลิกระหว่างอนิเมชันยังไม่จบ) → `clearTimers()` + `done()` ซึ่งถอด `bN-in`
- **ถอย beat** → ถอด `bN` กับ `bN-in` ของ beat ปัจจุบัน แล้วเรียก `settle[beat-1]()`
- **reset** → `clearBeats()` + reflow + `enter(1, true)` ให้ keyframe เริ่มนับหนึ่งใหม่

## ⚠️ กับดักที่เคยเจอมาแล้ว

**1. อย่าใส่ animation ทับกันบน element เดียวกัน**

จังหวะเด้งทักทาย (`greetHop`) อยู่บน `.sprite` ซึ่งเป็น **div ชั้นในของ `.actor`**
ไม่ได้อยู่บน `.actor` เอง — เพราะ `.actor` มี animation เข้าฉาก (`walkIn`) อยู่แล้ว
ถ้าใส่ `is-greet` ที่ `.actor` มันจะไปทับ `walkIn` แล้วพอถอดคลาสออก
**`walkIn` จะเริ่มเล่นใหม่ = ตัวละครเดินเข้ามาซ้ำ** (บั๊กนี้เคยเกิดจริง)

**2. `.stage` ต้อง `position: fixed` + `translate(-50%,-50%)`**

เคยใช้ `body { display:grid; place-items:center }` แล้ว scale — พอจอเล็กกว่า
1280px กล่องที่กว้างเกินจะถูกจัดชิดขอบแทนที่จะอยู่กลาง ทำให้เวทีหลุดออกนอกจอ

**3. `--accent` ถูกจองไว้แล้ว** หมวกแดงของหุ่นกินโควตาสีแดงของสไลด์นี้ไป
ทุกอย่างที่เหลือในหน้านี้ใช้ `--ink` / `--ink-soft` / `--ash` เท่านั้น

## ค่าที่แก้บ่อย

ทั้งหมดอยู่ต้น `<script>`

```js
var NEXT = "02-levels.html";
var PREV = null;                 // สไลด์แรก ไม่มีหน้าก่อนหน้า → ปุ่ม ◀ ถูก disable
var BEATS     = 2;
var AUTO_HOLD = [0, 2600, 9000]; // AUTO รอกี่ ms หลัง beat นั้นจบ ก่อนเดินหน้าเอง
```

| อยากแก้ | ไปที่ |
| --- | --- |
| ข้อความในกรอบ title | `<div class="title-frame">` ใน HTML |
| ตำแหน่งกรอบ title | `.title-frame { top: 76px }` |
| ตำแหน่ง `▶ LET'S BEGIN` | `.begin { top: 336px }` |
| ระดับพื้น | `.floor { bottom: 28px }` **และ** `.cast { bottom: 28px }` (ต้องเท่ากัน) |
| ขนาดตัวละคร | `.actor { --char-size: 200px }` |
| ระยะห่างสองตัว | `.cast { gap: 96px }` |
| ความเร็วเข้าฉาก | `walkIn` / `floatIn` `2.8s` — **ถ้าแก้ ต้องแก้ `at(2950)` กับ `at(4100)` ใน JS ตามด้วย** |
| คำใน bubble | `HUMAN_LINES` / `ROBOT_LINES` (สัญลักษณ์ล้วน อ่านไม่ออกโดยตั้งใจ) |
| ตำแหน่ง bubble | `.bubble { bottom: calc(var(--char-size) * .84) }` + `.actor-human/.actor-robot .bubble { left/right }` |

## หมายเหตุ bubble

- วางอยู่ **เฉียงบนฝั่งนอก** ของแต่ละตัว (คนอยู่ซ้าย หุ่นอยู่ขวา) หางชี้เข้าหาตัวละคร
- เนื้อในเป็นสัญลักษณ์ `▪▪▪ ? ! … ♪ 0101 ✓` **ตั้งใจให้อ่านไม่ออก** —
  สื่อแค่ว่ากำลังคุยกันอยู่ ไม่ให้คนดูมัวอ่านแทนที่จะฟังคนพูด
- idle loop สุ่มคำและสุ่มจังหวะ 2–4 วิ คุยไปเรื่อยๆ ตราบใดที่ยังค้างหน้านี้
