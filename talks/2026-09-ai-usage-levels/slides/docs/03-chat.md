### ทำไมบทเป็นแบบนี้

- **root cause ต้องเป็นข้อมูลเฉพาะ user รายนั้น** — EMP042 เพิ่งย้ายจากแผนก Sales
  ไป Finance เมื่อวาน แต่ฝั่งสิทธิ์ยังไม่ได้ sync ตาม (ในตาราง `users` แผนกเป็น
  Finance แล้ว แต่ฝั่ง permission ยังค้างเป็น Sales — `authorize.js:64` เทียบกับ
  ฝั่งที่ค้างอยู่ เลยปฏิเสธ) **เป็นสิ่งที่ AI ไม่มีทางเดาถูกถ้าเราไม่บอก**
  → ส่งไม้ต่อสไลด์ context engineer พอดี
- **เล่าเป็นภาษาธุรกิจก่อน แล้วค่อยยกหลักฐานทางเทคนิคตามหลัง** ตลอดทั้งสามสไลด์

- **⚠️ เรื่องย้ายแผนกต้องโผล่ที่ข้อความที่ 7 เท่านั้น** ไม่ใช่ข้อความแรก

- **AI ต้องดูฉลาดแต่ข้อมูลไม่พอ ไม่ใช่ดูโง่** คำเดาแรก (account lock /

### ตู้ rack (`.rack`)

เป็น **div ล้วน ไม่ใช่ SVG** กว้าง 86 สูง 120 (กว้างครึ่งเดียวของบ้านเดิม สูงเท่าเดิม)
แถบหัวสีป้าย + ช่องเซิร์ฟเวอร์ 4 ช่อง ช่องละ LED + ช่องระบายอากาศ

**ตู้อยู่ `z-index: 2` ส่วน `.pawn` อยู่ `1`** — หุ่นเลย *เลื่อนเข้าไปหลังตู้* จริงๆ
ไม่ใช่แค่จางหาย (ยังคง `is-hidden` ไว้เป็นตัวปิดท้ายกันหลุด)

**micro animation ตอนหุ่นอยู่ในตู้** = คลาส `is-busy` บน `.rack`
ไฟ LED เปลี่ยนจากกะพริบช้า 3.4s เป็นถี่ 0.48s + มีแถบสแกนเขียวไล่จากบนลงล่าง
เอาออกตอนหุ่นโผล่ออกมา → ตู้บอกสถานะว่า "หุ่นกำลังทำงานอยู่ข้างใน"

> ตู้ rack เป็นที่เดียวในเด็คที่**ใช้สีนอกโทน ink** — เขียว `--grass-deep`
> กับแดง `--accent` ที่ไฟ LED (user อนุมัติให้มีไฟสีได้) ที่เหลือคุมโทนเดิม

> **ไม่มีสไปรต์หุ่นท่าเดิน** — มีแค่ `robot` / `robot-left` / `robot-right`
> หุ่นเลย "ลอย" ไปมาแทนที่จะเดิน ซึ่งตรงกับสไลด์ 1 ที่หุ่นลอยเข้าฉากอยู่แล้ว
> ส่วนคนมีท่าเดินครบ แต่ไม่ได้ใช้เพราะคนไม่เคยขยับ

ตัวจับเวลาของฉากอยู่ในอาเรย์ **`sceneT` แยกจาก `timers` ของ beat** โดยตั้งใจ —
`clearTimers()` ตอนกดเดินหน้า/ถอย/reset จะได้ไม่ไปล้างลูปนี้ทิ้ง

## กลไกสำคัญ: แชทเลื่อนขึ้นเองโดยไม่มี scrollbar

```
.viewport  overflow:hidden + mask ไล่จางที่ขอบบน 0→92px
.feed      position:absolute; bottom:0   ← กองจากล่างขึ้นบน
```

`.feed` ยึดก้นไว้ ข้อความใหม่ต่อท้ายเสมอ ส่วนที่โตพ้นกล่องจะทะลุขึ้นไปข้างบน
แล้วโดน `overflow:hidden` ตัด + mask ไล่จาง **ไม่มี scroll ไม่มีการย่อขนาด**

**ทำให้ลื่นยังไง** — ถ้าปล่อยตามธรรมชาติกองจะ "กระตุก" ขึ้นทีเดียว เลยใช้ทริก
ใน `push()`:

```js
feed.appendChild(el);
var h = el.offsetHeight;
el.style.marginTop = -h + "px";   /* หักความสูงตัวเองทิ้ง → กองไม่ขยับ */
el.style.opacity = "0";
el.offsetHeight;                  /* บังคับ reflow ก่อน ห้ามตัดทิ้ง */
el.style.transition = "margin-top .36s ..., opacity .3s ...";
el.style.marginTop = "0px";       /* คลายกลับ → ดันทั้งกองขึ้นพร้อมกัน */
```

> บรรทัด `el.offsetHeight;` ที่ดูเหมือนโค้ดขยะ **ห้ามลบ** — เป็นการบังคับ
> reflow ให้เบราว์เซอร์บันทึกค่าเริ่มต้นไว้ ถ้าไม่มี transition จะไม่เล่นเลย

`.msg` ใช้ `padding-top: 15px` แทน `margin-top` ในการเว้นระยะ **โดยตั้งใจ**
เพราะ `margin-top` ถูกจองไว้ให้อนิเมชันข้างบนใช้

## กลไกสำคัญ: append กับ rebuild

ต่างจากสไลด์ 1–2 ที่ใช้คลาส `bN` / `bN-in` — สไลด์นี้ DOM เปลี่ยนจริง
เลยแยกทางเดินเป็นสองแบบใน `setBeat()`

| กรณี | ทำอะไร |
| --- | --- |
| `n === beat + 1` (เดินหน้าปกติ) | `push()` — ต่อข้อความใหม่ทีละใบพร้อมอนิเมชัน |
| อย่างอื่น (ถอย / reset / กระโดด / reduced-motion) | `rebuild()` — ล้าง `.feed` แล้ววาดใหม่ 1..n ทันทีไม่มีอนิเมชัน |

ทำให้ถอยหลังกับ reset ได้ผลตรงกันเสมอโดยไม่ต้องเก็บ state อะไรเพิ่ม

## micro loop: "AI กำลังพิมพ์"

จุดสามจุดในฟองฝั่ง AI จะโผล่**ทุกครั้งที่จบ beat แล้วตาถัดไปเป็นของ AI**
(คือหลังข้อความฝั่งเราทุกใบ) เป็น element ชั่วคราวคลาส `.typing`
ไม่ได้อยู่ใน `MSGS` — `addTyping()` / `clearTyping()` จัดการเอง

`push()` เรียก `addTyping()` ที่ `at(400)` **หลังอนิเมชันจบ** ไม่งั้นกองจะกระตุกซ้ำ
ส่วน `rebuild()` เรียกทันทีเพราะไม่มีอนิเมชันอยู่แล้ว


หน้าตาเปลี่ยนตามเครื่องที่ฉาย) แต่ `🙂👌` กับ `✅` เป็น **สีหน้า/อารมณ์ของตัวละคร**
ซึ่ง user อนุมัติเป็นข้อยกเว้นแล้ว **ไอคอน UI ยังห้ามใช้ emoji เหมือนเดิม**

**4. `--accent` ใช้จุดเดียว** = ป้าย "จุดเปลี่ยน — AI ขอ context เอง"
ใต้ข้อความที่ 10 ห้ามเอาแดงไปใช้ที่อื่นในสไลด์นี้อีก เพราะจุดนั้นคือ
ที่ที่อยากให้สายตาไปหยุดพอดี

## ค่าที่แก้บ่อย

```js
var NEXT = "04-prompt.html";   // ยังไม่มีไฟล์นี้
var PREV = "02-levels.html";
var MSGS = [ ... ];            // บทสนทนา — เพิ่ม/ลดได้อิสระ BEATS ตามอัตโนมัติ
```

| อยากแก้ | ไปที่ |
| --- | --- |
| บทสนทนา | `MSGS` — `who` `"you"`/`"ai"`, `p[]` = ย่อหน้า |
| แนบรูปหน้าจอ | ใส่ `shot: true` ในข้อความนั้น (รูปเป็นกล่องพิกเซล ไม่ใช่ไฟล์จริง) |
| แนบ log/โค้ด | ใส่ `log: "บรรทัด\nบรรทัด"` (ขึ้นบรรทัดด้วย `\n`, escape ให้อัตโนมัติ) |
| ป้ายจุดเปลี่ยน | ใส่ `mark: "ข้อความ"` |
| รูป avatar | `AVATARS` (กริด 13×13, `[x, y, w, h]`) — ขนาดที่ `.av { width }` |
| ขนาดกล่องแชท | `.chatbox { left/top/width/height }` |
| ความแรงของการไล่จางขอบบน | `.viewport` `mask-image` — เลข `92px` คือจุดที่ทึบเต็ม |
| ความเร็วการเลื่อน | `push()` `"margin-top .36s"` |
| ตำแหน่ง/จังหวะฉากล่าง | `BOT_HOME` `BOT_TALK` `GUY_X` และฟังก์ชัน `scene()` |
| คำในบอลลูนของฉากล่าง | `GUY_LINES` / `BOT_LINES` (สัญลักษณ์ล้วน) |
| เวลารอของ AUTO | `AUTO_HOLD` — คำนวณจากความยาวข้อความ 1.9–4.2 วิ ใบสุดท้าย 7 วิ |
